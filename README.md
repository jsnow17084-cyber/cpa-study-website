# CPA Study Hub

A simple static CPA study website.

## Files
- index.html — main webpage
- style.css — design and responsive layout
- script.js — quiz and button interactions

## Publish
Upload all files to a public GitHub repository and enable GitHub Pages from:
Settings → Pages → Deploy from a branch → main → /(root)

## Important
Replace the sample educational content with your own materials and verify current CPA requirements with the relevant official authority.
